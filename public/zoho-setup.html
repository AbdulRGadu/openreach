Connect your Zoho Mail account

Each self-hosted workspace uses its own Zoho account, OAuth credentials, and verified sender address. Keep sending in dry-run mode while you set this up.

1. Create OAuth credentials

  1. Sign in as the Zoho Mail account owner and create a Self Client in the Zoho API Console.
  2. Generate a grant code with ZohoMail.messages.CREATE,ZohoMail.accounts.READ.
  3. Exchange it at your region’s Zoho OAuth endpoint and securely save the refresh token.

2. Configure Cloudflare

  1. Set ZOHO_MAIL_BASE and ZOHO_ACCOUNTS_BASE for your Zoho data center.
  2. Call Zoho’s accounts API and place the matching accountId in ZOHO_ACCOUNT_ID.
  3. Store ZOHO_CLIENT_ID, ZOHO_CLIENT_SECRET, and ZOHO_REFRESH_TOKEN as Cloudflare Worker secrets. Never enter them in this dashboard.

3. Verify sender identity

In Zoho Mail, confirm the sender address and display name under Send Mail As. Use that exact identity in the setup wizard and confirm it there. Zoho only accepts From addresses associated with the authenticated account.

Outreach Studio requires human approval for every real outbound message. Keep DRY_RUN=true until you have tested the verified sender with an address you control.
